## 📌 Description
Batch Document Matrix Converter provides automated cross-format batch conversion across massive document trees, supporting text, Markdown, HTML, RTF, and OpenDocument formats.

---

## ✨ Features
- Recursive folder scanning and batch matrix document conversion
- Format preservation across Markdown, HTML, OpenDocument, RTF, and Plain Text
- Customizable text normalization, character encoding auto-detection (UTF-8, UTF-16, ASCII)
- Comprehensive error logging, conversion audit trails, and status reports
- Multi-threaded execution engine for lightning-fast file processing

---

## 🛠️ Tech Stack & Architecture
- **Language / Framework**: Python 3.10+ / Qt (PySide6 / PyQt)
- **Core Modules**: Modular engine architecture, async event dispatching, decoupled utility functions
- **Target OS**: Windows, macOS, Linux

## 🚀 Quick Start & Installation

### Prerequisites
- **Python**: Version 3.10 or higher installed
- **Git**: Installed for cloning repositories

### Setup Instructions
```bash
# 1. Clone the repository
git clone https://github.com/hsinidev/004-Batch-Document-Matrix-Converter.git

# 2. Navigate to project directory
cd 004-Batch-Document-Matrix-Converter

# 3. Install required dependencies
pip install -r requirements.txt

# 4. Launch the Application
python app.py
```
*(Note: If `app.py` is absent, launch with `python main.py`)*
